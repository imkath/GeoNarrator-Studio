# GeoNarrator Studio

Herramienta para crear experiencias de scrollytelling geoespacial con mapas interactivos.

## Qué hace

- Editor de escenas narrativas vinculadas a coordenadas geográficas
- Transiciones suaves entre locaciones del mapa (Mapbox)
- Animaciones de scroll con Framer Motion
- Casos de uso: periodismo, turismo, educación, investigación

## Stack

- Next.js
- Mapbox GL JS (react-map-gl)
- Framer Motion
- Tailwind CSS

## Correr local

Requiere `NEXT_PUBLIC_MAPBOX_TOKEN` en `.env.local`.

```bash
npm install
npm run dev
```
